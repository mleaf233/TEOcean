# TEOcean 上游本地化webui

## 运行要求

需要安装 Node.js 18 或更高版本，并确保命令行可以运行 `node --version`。网页服务不需要安装任何 npm 依赖。

## 打开网页

双击 `start.cmd`。浏览器会自动打开：

```text
http://127.0.0.1:8732/
```

请保留弹出的 PowerShell 窗口。需要停止服务时，点击网页底部的“关闭本地服务”、在 PowerShell 窗口按 `Ctrl+C`，或直接关闭窗口。

如果默认端口被占用，可在 `tools/web` 目录打开 PowerShell，运行：

```text
node .\server.js --port 8733
```

## 页面功能

- **检查全部 / 检查所选**：检查上游本地化文件是否发生变化。
- **初始化基线**：为未跟踪的 Mod 建立初始基线；勾选“强制覆盖”后也会更新已有基线。
- **接受所选基线**：确认翻译跟进后，把所选 Mod 的当前上游提交设为新基线。
- **接受全部基线**：对全部已配置 Mod 执行接受操作，页面会先要求确认。
- **添加 Mod**：创建中文本地化骨架、保存上游来源，并可立即初始化基线。
- **查看报告**：发现更新后，可直接读取 `impl/todo/<modid>/upstream_changed.md`。
- **刷新列表**：重新读取 `upstream-sources.json` 和 `upstream-lock.json`。
- **取消当前任务**：同步卡住时，终止对应的 PowerShell 和 Git 子进程。
- **关闭本地服务**：安全停止网页服务；下次使用时重新双击启动文件。

网页服务由 [server.js](./server.js) 使用零依赖的 Node.js 标准库提供。实际同步操作仍由原来的 `upstream-localization.ps1` 完成，Node.js 只负责网页、状态缓存、后台任务和日志传输。

## 安全说明

- 服务只监听 `127.0.0.1`，局域网内其他设备无法访问。
- 修改基线前会显示确认窗口。
- 同步操作通过独立后台进程执行，网页仍可读取状态和日志。
- 同一时间只处理一个操作，运行时按钮会被禁用，避免重复提交。
- 页面关闭不等于服务停止；请使用网页底部的关闭按钮或直接关闭 PowerShell 窗口。
